Ciriú Ecommerce

Tecnologías

  • Angular

  • Java

  • TypeScript

  • Postgresql

  • Docker

  • Bootstrap

  • Mercado pago

Desarrollado a medida para la empresa Ciriú ubicada en la localidad de Hernando, Córdoba, Argentina. Brindándole la solución en la gestión de sus ventas y manipulación de los artículos en su catálogo. El desarrollo se hizo en Java con el framework Spring Boot para el BackEnd, implementando a Mercado Pago como pasarela de pagos, por otro lado, se utilizó Angular para el FrontEnd de la página, y como gestor de base datos se implementó PostgreSQL para almacenar la información.

Script Agroads

Tecnologías

  • Python

  • Excel

  • Playwright

Software para carga automatizada de maquinaria agrícola en Agroads. Bot que publica productos a partir de un archivo Excel y carpetas locales de fotos. Desarrollado en Python con Playwright para automatizar el navegador Chromium. Permite configurar credenciales, rutas y delays entre publicaciones. Incluye generación de ejecutable .exe con PyInstaller para distribución sin instalar Python. El cliente solo necesita el Excel con datos, la carpeta de fotos y las credenciales de Agroads.
